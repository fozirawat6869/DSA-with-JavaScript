# DSA with JavaScript

This repository contains Data Structures and Algorithms (DSA) programs implemented in JavaScript.

## Topics Covered

### Arrays
- Factorial Program
- Array Operations
- Searching
- Sorting

### Strings
- Count how many times a string appears in another string
- String Manipulation
- String Searching

## Technologies Used
- JavaScript

## How to Run

1. Clone the repository

```bash
git clone https://github.com/fozirawat6869/DSA-with-JavaScript.git
```

2. Open the project in VS Code

3. Run any JavaScript file

```bash
node filename.js
```
